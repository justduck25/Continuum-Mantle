Continuum Core 26.1.2-1.12.2

Fixes
- Tool/part models now render with proper 3D extrusion edges (fix #17). Opaque sprites now emit side quads matching vanilla's bakeSideFaces, fixing flat weapon models when thrown.

Continuum Core 26.1.2-1.12.1

Fixes
- Book pages now render with the correct uniform/alt fonts (official Mantle parity), fixing text wrapping and clipping.
- Book crafting/smelting recipes show correctly in multiplayer via server-synced recipe map (BookRecipes).
- Book text colors restored to official Mantle: page numbers 0xFFAAAAAA, cover title/subtitle in cover color with shadow, section labels black, overflow ellipsis black.
- Station screen titles and Inventory label fixed (alpha byte 0xFF) so they are no longer invisible on 26.1.
- Placed inventories can write enchantments. Chunk sync was using the built-in registries, which cannot see them.
- Standing in a custom fluid source no longer freezes the player, and those fluids drip.
- Fluid sprites and tint are read from the NeoForge fluid model, so a tank keeps another mod's color.

Compatibility
- This library release is intended for Continuum Construct 3.12.5 on Minecraft 26.1.2 / NeoForge 26.1.2.

Credits
- Book font, recipe sync, and color fixes by Arthur (therealarthur) with co-authoring by Claude.
- Extrusion side quads fix by Arthur with co-authoring by Claude.

Continuum Core 26.1.2-1.12.0

Fixes
- Item fluid transfers now cap to the container's stored amount or remaining capacity, preventing smeltery fluids from being over-drained during bucket and copper can interactions.
- Recipe fluid outputs now resolve registered fluid holders instead of leftover direct holders from datagen, so runtime drops and recipe results keep a stable fluid identity.
- Unbound datapack item tags no longer crash recipe tests during ingredient matching.
- Normal potions are registered without a leading underscore in their IDs.
- Datapack item tags are looked up from the live registry access, not only builtin item holders, so tagged items such as slimeballs match at runtime.

Compatibility
- This library release is intended for Continuum Construct 3.12.0.0 on Minecraft 26.1.2 / NeoForge 26.1.2.

Continuum Core 26.1.2-1.11.6

Fixes
- Fixed a recipe sync crash that could disconnect or crash clients when a datapack or third-party mod produced an empty fluid output during NeoForge recipe payload syncing.
- Empty fluid recipe outputs are now tolerated during network sync, while normal recipe/datagen validation remains strict.

Notes
- This targets the reported `FluidStack cannot be empty` / `neoforge:recipe_content` crash path.
- Tested by building the Core jar and loading a large modpack-style client until world load; the original fluid packet crash did not reproduce.
